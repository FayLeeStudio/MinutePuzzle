# MinutePuzzle ⏱️

一个 24 小时 GameJam 作品，主题 **1min（一分钟）**。

> 每关都是一局「一分钟拼图」：中间是一张**实时变化的画面**，你要趁 60 秒倒计时归零前，把打散的碎片拖回正确位置、拼成完整画面。碎片不是静态截图，而是那张画面「对应区域、此刻」的实时取景框，所以只能靠**空间位置 / 相对关系**来拼。

## 当前版本关卡（线性闯关，4 关）

1. **倒计时**  
   七段数码管显示屏，60 → 00 每秒一跳。
2. **贪吃蛇**  
   自动对局的贪吃蛇，沿预设路径持续移动，60 秒内逐渐吃满屏幕。
3. **仓鼠球**  
   一个简化的迷宫滚球关卡，画面会实时变化；可用 **W/A/S/D** 或设备倾斜控制。
4. **摄像头**  
   实时摄像头画面，拼的就是「此刻的你」。通关后会进入 **3-2-1 拍照定格**，并尝试把截图保存到本地。

## 玩法

- 中间是一个 **4×3 = 12 格**的拼合区，显示当前关的实时画面。
- 开局先看一眼完整画面，点「开始游戏」后，12 块碎片会瞬间打散到外围放置区。
- **拖拽**碎片到中间网格，松手会自动**吸附**到最近的格子。
- 如果目标格已有碎片，拖上去会触发**交换位置**。
- 全部碎片回到各自正确位置即胜利。

## 胜负与流程

- 在倒计时归零前把 12 块全部拼对：**胜利**。
- 倒计时越过 **00** 仍未拼完：**失败**。
- 胜利后进入下一关；最后一关通关后可从头再玩。
- 摄像头关通关后会先播放 **3-2-1** 倒计时和白闪效果，再尝试把当前画面导出为 PNG。

## 操作

- **鼠标 / 触屏拖拽**：拖动拼图碎片。
- **W / A / S / D**：控制第 3 关仓鼠球移动。
- **设备陀螺仪 / 重力感应**：在支持的移动设备上，可用于控制第 3 关仓鼠球。
- 浮层按钮用于开始游戏、进入下一关或重试。

## 运行

项目为纯原生 **vanilla JavaScript + Canvas 2D**，零依赖、零构建，主程序只有一个 `index.html`。

- **第 1～3 关**：可直接打开 `index.html` 运行。
- **第 4 关（摄像头）**：需要在 **安全环境** 下运行，即 `https` 或 `localhost`，并允许浏览器访问摄像头。
- 如果要体验完整流程，建议通过本地服务器或线上托管打开，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 技术说明

- 单文件结构：`index.html` 中同时包含 HTML、CSS、JavaScript。
- 关卡由 `LEVELS` 配置数组驱动，通用拼图流程和单关内容解耦。
- 每一帧都会先把当前关卡的完整动态画面绘制到**离屏 canvas**，再由拼图碎片按各自区域裁切显示。
- 倒计时使用 `performance.now()` 推算，不依赖逐帧累加。
- 贪吃蛇关使用确定性步进逻辑，保证画面按时间推进。
- 仓鼠球关包含简单的输入、速度、阻力和墙体碰撞逻辑。
- 摄像头只在对应关卡申请权限并启用，离开关卡后关闭；通关时会尝试把镜像后的摄像头画面保存到本地。

## 素材与资源

- 当前版本没有外部图片、音频或视频素材文件。
- 倒计时、贪吃蛇、仓鼠球画面都由代码实时绘制。
- 摄像头内容来自玩家设备的实时输入，仅在本地运行时处理，不上传到服务器。
