# MinutePuzzle ⏱️

一个 24 小时 GameJam 作品,主题 **1min(一分钟)**。

> 你拼的那张「图」本身就是一块倒计时显示屏——拼图内容 = 剩余时间,二者是同一个东西。

## 玩法

- 中间是一个 **3×4 = 12 格**的拼合区,呈现一块**实时七段数码管显示屏**,数字从 **60 倒数到 00**,每秒一跳。
- 开局先看一眼完整的钟,点「开始游戏」后,12 块方形碎片会瞬间打散到外围。
- **拖拽**碎片到中间网格,松手会**吸附**到最近的格子。
- 碎片是显示屏的**实时取景框**(不是静态快照):时钟一跳,所有碎片内容同步变化。
- 每块碎片的数码管内容都落在**自己的中线上**,所以光看单块碎片判断不出它该放哪——只能靠**空间位置/相对关系**来拼。

## 胜负

- 归零(到 **00**)前把 12 块全部拼对 → **胜利**,记录定格时的剩余秒数。
- 倒计时越过 00 仍未拼完 → **判负**。
- 结束后可一键重玩。

## 操作

- 鼠标 / 触屏拖拽即可(基于 pointer 事件,自动兼容)。

## 运行

纯原生 **vanilla JavaScript + Canvas 2D**,零依赖、零构建。直接**双击 `index.html`** 用浏览器打开即可,无需本地服务器。

## 技术说明

- 单文件 `index.html`(HTML + CSS + JS 同文件)。
- 倒计时用时间戳推算(`performance.now()`),不逐帧累加。
- 显示屏每帧画到离屏 canvas,碎片用 `drawImage` 取对应子矩形;七段数码管的骨架对齐网格中线。

## 素材出处

全部画面由代码实时绘制,无外部图片 / 音频素材。
